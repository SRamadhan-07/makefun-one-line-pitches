A Python program — standard library only, no network — that writes one sentence to /output/entry.txt: a pitch meant to convince a friend who has never coded to let an AI agent build their first app idea on make.fun. The sentence is 72 characters, inside the competition's gate of 1 to 240 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
